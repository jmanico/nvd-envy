# NVD Envy

A planned local command-line tool for joining all published CVE records with NVD and FIRST EPSS data. It will show CVEs absent from a completed NVD snapshot and CVEs with an EPSS probability of at least 10% for observed exploitation in the next 30 days.

The repository currently contains specifications and a logo. No application has been built or verified.
